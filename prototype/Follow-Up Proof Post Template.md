# Follow-Up Proof Post Template

Source loop: [[../../Improvement-Loops/X Feedback Feature Factory Loop|X Feedback Feature Factory Loop]]

Use this after a public feedback item ships as a Hermes Agent feature or artifact.

## Short X post

> Shipped this from X feedback: <one-line feature>
>
> What changed:
> - <observable behavior>
> - <command or UI path>
> - <proof artifact / commit / repo>
>
> Source feedback: <URL>
> Build note: <x-intel note or GitHub URL>

## Longer proof thread

1. Feedback signal: quote the exact ask and link the X source.
2. Triage: show the feature-intake score and why it was safe/reversible.
3. Sandbox: name the blank Hermes profile used for the test.
4. Ship: link the commit, package, or repo.
5. Invite next feedback: ask for one concrete follow-up.

## Guardrails

- Do not imply a feature is merged if it only exists as a prototype.
- Do not post secrets, internal paths that should remain private, or raw logs with tokens.
- Prefer exact commands and visible screenshots over vague “we improved it” claims.
